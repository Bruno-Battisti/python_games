# python_games

Coleção de jogos simples em Python com interface gráfica (Tkinter).

## Jogos

- [x] Jogo da Velha (`jogo_da_velha.py`)
- [x] Forca (`forca.py`)
- [x] Pedra, Papel e Tesoura (`pedra_papel_tesoura.py`)
- [x] Adivinhe o Número (`adivinhe_o_numero.py`)
- [x] Jogo da Memória (`jogo_da_memoria.py`)
- [x] Campo Minado (`campo_minado.py`)
- [x] Quiz (`quiz.py`)

## Como jogar

Requer apenas Python 3 com Tkinter (já incluso na instalação padrão).

```bash
python nome_do_jogo.py
```
